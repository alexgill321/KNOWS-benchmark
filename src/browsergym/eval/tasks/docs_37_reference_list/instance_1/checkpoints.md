# Checkpoints

This task has 160 points in total.

## Checkpoint 1 (30 pt, 3 steps × 10 pt each): Lecture Title

### Outcome Evaluation:
- Check that each lecture (and only lectures) has an associated title in 'Month/Day: Lecture title' format.(10 pt, proportional)
- The title of each lecture should be of size 'Heading 3'(10 pt, proportional)
- Each title should be bookmarked(10 pt, proportional)

## Checkpoint 2 (40 pt, 4 steps × 10 pt each): Topics bullet lists

### Outcome Evaluation:
- Check if the title of the bullet lists belong to one of the following categories: "Academic Articles", "Textbooks", "Blogs", "Code Implementations", "Tutorials", "Wikipedia", "Presentations".(10 pt, proportional)
- Check that each bullet list starts with the right title in bold.(10 pt, proportional) 
- Check that there are no empty bullet lists.(10 pt, proportional)
- Check that there are no bullet lists with titles that don't match the categories(10 pt, proportional)

## Checkpoint 3 (60 pt, 6 steps × 10 pt each): Reference links

### Outcome Evaluation:
- All reference links under each category of each lecture are present without duplicates.(10 pt, proportional)
- Check that each link is categorized correctly i.e. a link that is a blog should be categorized as a blog and not as textbooks.(10 pt, proportional)
- Check that each link has a slide number along with it. (10 pt, proportional)
- Check that the hyperlink is in the correct format i.e. using the resource title as the anchor text instead of the raw URL. (10 pt, proportional)
- Check that the slide numbers are in the correct format of "Slide: {number1, number2,...}". (10 pt, proportional)
- Check that the name of the link is relevant to the webpage it opens.(10 pt, proportional)

## Checkpoint 4 (30 pt, 3 steps × 10 pt each): Multiple references

### Outcome Evaluation:
- Check that hyperlinks of references that appear in multiple slides are in bold.(10 pt, proportional)
- Check that hyperlinks of references that appear in multiple slides are in 'dark green 2'.(10 pt, proportional)
- Check that there are no duplicates in the slide numbers for hyperlinks that appear  in multiple slides.(10 pt, proportional)
