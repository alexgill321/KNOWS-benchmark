# Checkpoints

This task has 22 points in total.

## Checkpoint 1 (7pts):

There is a spreadsheet with the requested information.

### Outcome Evaluation:

- There is a column/row with the name of each stock.
- There is a column/row with the ticker symbol of each stock.
- There is a column/row with the current price of each stock.
- There is a column/row with the past price of each stock.
- There is a column/row with the gain/loss of each stock.
- There is a column/row accounting for the number of shares owned for each stock.
- There is a column/row with the total value of each stock.

## Checkpoint 2 (10pts):

The stocks and information are correct and match the task requirements.

### Outcome Evaluation:

- Each of the 7 stocks matches a top 7 highest market cap semiconductor company as of December 31, 2025 (1 point per correct stock).
- The past price of each stock is correct.
- The current price of each stock is correct.
- The gain/loss of each stock is correct.

## Checkpoint 3 (2pts):

A website containing the information was visited.

### Outcome Evaluation:

- The website trace contains a URL that has information about the top 7 semiconductor companies by market cap as of December 31, 2025.
- The website trace contains a URL that has information about the past price of each stock.

## Checkpoint 4 (3 pts):

A line chart showing the current total value of each position relative to the others was created.

### Outcome Evaluation:

- A line chart was created in the spreadsheet.
- The line chart contains each of the stocks.
- The line chart correctly shows the current total value of each position.
