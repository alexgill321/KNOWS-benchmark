# Checkpoints

This task has 190 points in total.

## Checkpoint 1 (20 pt, 2 steps × 10 pt each): Lecture Title

### Outcome Evaluation:

- Each lecture (and only lectures) has an associated title in 'Session #: Lecture title' format, where # is the session number. (10 pt, proportional)
- The title of each lecture should be of size 'Heading 3'. (10 pt, proportional)

## Checkpoint 2 (40 pt, 4 steps × 10 pt each): Topics bullet lists

### Outcome Evaluation:

- The following categories found as the titles of the bullet lists: "Research Papers", "Wikipedia", "Presentations". (10 pt, proportional)
- Each bullet list starts with the right title in bold. (10 pt, proportional)
- No empty bullet lists. (10 pt, proportional)
- No bullet lists with titles that don't match the categories. (10 pt, proportional)

## Checkpoint 3 (90 pt, 9 steps × 10 pt each): Reference links

### Outcome Evaluation:

- All reference links under each category of each lecture are present. (10 pt, proportional)
- No duplicate reference links. (10 pt, proportional)
- Each link is categorized correctly i.e. a link that is a Wikipedia article should be categorized as "Wikipedia" and not as "Research Papers". (10 pt, proportional)
- The slide number list for each reference matches the gold list of slides where the link is actually referenced. (10 pt, proportional)
- Each hyperlink is in the correct format i.e. using the resource title as the anchor text instead of the raw URL. (10 pt, proportional)
- The slide numbers are in the correct format of "Slide: {number1, number2,...}". (10 pt, proportional)
- The name of each link is relevant to the webpage it opens. (10 pt, proportional)
- A separate "Inactive Links" section exists at the end of the document, and every link placed under it is verified to be a dead link. An empty section passes; otherwise each verified dead link earns a point, scaled to 10. (10 pt, proportional)
- Within each category, the bullets are sorted in descending order by number of slide references, breaking ties alphabetically by anchor text. (10 pt, proportional)

## Checkpoint 4 (40 pt, 4 steps × 10 pt each): Multiple references

### Outcome Evaluation:

- Hyperlinks of references that appear in multiple slides are in bold, and only the hyperlink text is bold (not the surrounding bullet text). (10 pt, proportional)
- Hyperlinks of references that appear in multiple slides are italicized, and only the hyperlink text is italicized (not the surrounding bullet text). (10 pt, proportional)
- Hyperlinks of references that appear in multiple slides are colored 'dark purple 1', and only the hyperlink text is colored (not the surrounding bullet text). (10 pt, proportional)
- No duplicates in the slide numbers for hyperlinks that appear in multiple slides. (10 pt, proportional)
