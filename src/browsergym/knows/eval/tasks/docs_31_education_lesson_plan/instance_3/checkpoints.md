# Checkpoints

This task has 145 points in total.

## Checkpoint 1 (15pt): Related Topics

The document has two to three main level topics that match the given subject and are appropriate for the specified audience.

### Outcome Evaluation
- All top level bullet points are topics related to the given subject for the instance.
- There is at least two main level bullet point topics and no more then three main level bullet point topics.
- All topics are unique (no duplicate topic names).
- All topics are appropriate for the specified educational level (e.g., not too advanced for elementary, not trivially shallow for college).
- All topics are engaging and likely to be enjoyed by students at the specified level (the "fun" criterion from the task).

## Checkpoint 2 (45pt): Website url's match 

The document has valid urls's under each topic bullet point.

### Outcome Evaluation
- Ensure that each topic has at least 4 websites listed as sub bullets
- Ensure that the 4 websites under each topic are unique (no duplicate URLs within a topic, after normalization)
- Ensure that each website is valid
- Ensure the agent has visited each website
- Ensure that each website is related to the topic

## Checkpoint 3 (35pt): Website Facts are valid

Ensures that facts exist in the website.

### Outcome Evaluation
- Ensure that each website bullet has at least 5 sub bullets for facts
- Ensure that the 5 facts under each website are unique (no duplicate fact text)
- Ensure that each fact does exist in the website.

## Checkpoint 4 (20pt): Check color coded facts

Ensure that exact facts are copied into the summary and they are properly color coded by topic.

### Outcome Evaluation
- Ensure that all facts are copied in correctly.
- Ensure that the facts are formatted as bullet points.
- Ensure that each subtopic facts are all color coded the same
- Ensure that each topic uses a different color from every other topic (no color shared between topics)

## Checkpoint 5 (20pt): Check Topic Images

Check that there are correct images for each topic and they are correctley aligned. 

### Outcome Evaluation
- Ensure every topic from the lesson plan has exactly one matching image (one-to-one; a single image must not satisfy multiple topics).
- Ensure that the images are at the bottom of the last page
- Check that images are aligned side by side
- Ensure that each image depicts the topic concept or related people, not merely a surface keyword association.

## Checkpoint 6 (10pt): Check lesson summary

Ensure that lesson summary exists and they are written from the facts.

### Outcome Evaluation
- Ensure that lesson summary is present.
- Ensure that the lesson summary is written using the facts collected.
