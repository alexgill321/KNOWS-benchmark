# Checkpoints

## Checkpoint 1 (65 pt): Header & Subheader

The header and subheader follow proper structure and contain correct information.

### Outcome Evaluation
- Event name text box appears at the top of the page
- Event name text is centered on the slide
- Event name text has bold font
- Event name text has font size >= 20
- Event name text color is **Mint Green**
- Event name reads "Becoming a National Geographic Photographer"
- Subheader exists below the main header
- Subheader is left-aligned
- Subheader is in italic font smaller than the main header
- Subheader contains date (September 15th)
- Subheader contains location (1030 North Olive Road, Tucson)
- Subheader contains host (Center for Creative Photography at University of Arizona)
- Visual contrast is clear between header and subheader text

## Checkpoint 2 (20 pt): Logo

The logo is properly placed, scaled, and sourced.

### Outcome Evaluation
- The logo is the **Center for Creative Photography at University of Arizona** logo

The central body contains an accurate and well-sourced summary of the topic.

- Summary is 1–2 paragraphs
- Summary covers Photography
- Summary clearly tied to Michael Yamashita's work or field of expertise

- At least 2 reputable, stable sources (e.g., university, professional association, major news outlet, encyclopedia, or speaker's official website) are used
